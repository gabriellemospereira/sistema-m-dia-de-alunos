# 📚 Sistema de Cálculo de Média Escolar em Python

Projeto desenvolvido para praticar lógica de programação em Python.

Este programa solicita o nome do aluno e duas notas, calcula a média e informa a situação final:

- ❌ Reprovado (média < 5.0)
- ⚠️ Recuperação (média entre 5.0 e 6.9)
- ✅ Aprovado (média ≥ 7.0)

---

## 🚀 Funcionalidades

- Entrada de dados via terminal
- Cálculo automático da média
- Estrutura condicional (`if`, `elif`, `else`)
- Formatação de saída
- Exibição personalizada com o nome do aluno

---

## 🛠 Tecnologias Utilizadas

- Python 3
